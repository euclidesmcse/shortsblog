# assets/

Montado em `/app/assets` (somente leitura) nos containers de aplicação.

Coloque aqui o que o motor deve usar na identidade visual das imagens
geradas — logo, fontes próprias, marca d'água. Hoje a camada de marca usa
apenas as cores de `BRAND_PRIMARY_COLOR` / `BRAND_ACCENT_COLOR` e a fonte
DejaVu do sistema; este diretório é o ponto de extensão para isso mudar.
